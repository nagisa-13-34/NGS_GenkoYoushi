# NGS_GenkoYoushi

Adobe After Effects で縦書き用の原稿用紙グリッドを作成する JSX スクリプトです。設定したマス数や線の色、太さをもとにシェイプレイヤーを生成し、After Effects 上でサイズや位置を調整できます。

## 主な機能

- 縦方向のマス数と横方向の行数を指定してグリッドを作成
- グリッド全体のサイズ、横間隔、枠線の色と太さを調整
- マスの塗りつぶしと塗りの色を設定
- 選択中の原稿用紙レイヤーから設定を読み込み
- 設定をプリセットとして保存、読込、適用、削除

プリセットは After Effects のアプリケーション設定に保存されます。プロジェクトファイルには含まれず、別のPCやAfter Effects環境とは自動で共有されません。

## 動作環境

- Adobe After Effects（ExtendScript と ScriptUI に対応する環境）
- 外部ライブラリは不要

対応する After Effects のバージョンは確認できていません。

## インストールと起動

### すぐに実行する

1. After Effects を起動します。
2. **ファイル > スクリプト > スクリプトファイルを実行...** を選びます。
3. `NGS_GenkoYoushi.jsx` を選択します。

### パネルとして使う

1. `NGS_GenkoYoushi.jsx` を After Effects の `Scripts/ScriptUI Panels` フォルダにコピーします。
   - Windows: `C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\ScriptUI Panels\`
   - macOS: `/Applications/Adobe After Effects <バージョン>/Scripts/ScriptUI Panels/`
2. After Effects を再起動します。
3. **ウィンドウ** メニューから `NGS_GenkoYoushi` を開きます。

## 基本的な使い方

1. グリッドを作成したいコンポジションを開きます。
2. パネルでサイズ、マス数、行数、間隔、線の色や太さを設定します。
3. 塗りつぶしを使う場合は有効にし、色を選びます。
4. **適用** を押すと、コンポジションに `GenkoYoushi` シェイプレイヤーが追加されます。
5. 生成したレイヤーを選び **Effect→UI** を押すと、そのレイヤーの設定をパネルに読み込めます。

コンポジションを開いていない場合は、1920×1080、10秒、30fps のコンポジションが作成されます。**適用** のたびに新しいシェイプレイヤーが追加されます。

## 設定項目

| 項目 | 説明 | 初期値 |
| --- | --- | ---: |
| サイズ | グリッド全体の拡大率（%） | 100 |
| 一行の行数 | 縦方向に並べるマス数 | 8 |
| 行数 | 横方向に並べる列の数 | 5 |
| 横間隔 | 列と列の間隔（px） | 6 |
| 線の太さ | マス目の枠線の太さ（px） | 2 |
| 枠の色 | マス目の枠線の色 | 青系 |
| 塗りの色 | マスの塗りつぶし色 | 白 |
| 塗りつぶしを有効 | マスを塗りつぶすかどうか | オフ |

## プリセット

パネルの **プリセット** タブで設定を管理できます。

- **UI保存**: パネルに入力した設定を保存
- **レイヤー保存**: 選択中の `GenkoYoushi` レイヤーの設定を保存
- **読込**: 保存した設定をパネルに読み込む
- **適用**: 保存した設定で新しい原稿用紙レイヤーを作成
- **削除**: 選択したプリセットを削除

## ファイル一覧

| ファイル | 用途 |
| --- | --- |
| `NGS_GenkoYoushi.jsx` | 推奨版。編集可能なソースで、設定パネルとプリセット機能を含みます。 |
| `NGS_GenkoYoushi.jsxbin` | コンパイル済みスクリプトです。ソースを読む・変更する場合は `.jsx` を使ってください。 |
| `NGS_GenkoYoushi_4.jsx` | 別バージョンのパネルスクリプトです。 |
| `NGS_GenkoYoushi_5.jsx` | 別バージョンのパネルスクリプトです。 |
| `NGS_GenkoYoushi_free.jsx` | グリッド作成と基本設定に絞った簡易版です。 |
| `NGS_GenkoYoushi_apply_preset_layer_index_namecheck_applyfix.jsx` | プリセット適用処理を含む別バージョンです。 |

最初に使う場合は `NGS_GenkoYoushi.jsx` を選んでください。
